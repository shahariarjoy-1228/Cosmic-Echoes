# Live demo

Start from the root page on loopback HTTP in Edge. Check output volume, keep the sample WAV and screenshots open locally, and use a fresh recording. The root app ends each take at 60 composition seconds. Use Pause during longer explanations and Stop between takes to keep the timing predictable.

## Two minutes

| Time | Action and narration |
|---|---|
| 0:00–0:20 | Show Deep Space and Quiet Orbit. “Every star has a voice. This preset gives one root and two generations.” Press Start session and Place center star. Leave a few seconds for the echoes. |
| 0:20–0:45 | Switch to Nebula Bloom in the same take. Click the sky away from the center. Point to the 40 stars per root and the visible branching. Pause once the echoes appear, then Resume. |
| 0:45–1:10 | Enter Focus mode briefly. Explain that the Canvas follows the audio session clock. Exit and Stop after several notes. Keep the elapsed composition time below 60 seconds if you want to demonstrate an early cut. |
| 1:10–1:40 | Press Replay, then Stop the replay. Prepare WAV and Download WAV once ready. Play a few seconds from the independent player if already open. |
| 1:40–2:00 | Show the six deliverables and verification. Mention the offline sample and the remaining archive work. |

| 1:20–2:15 | Replay the first take briefly, Stop replay, then Prepare WAV and Download WAV. Explain the early-stop cutoff and show or play the separate natural-completion sample. Finish this segment before starting the next recording. |

## Fallback

If the page will not load, check the server folder and loopback URL. If audio is silent after a genuine Start click, check tab mute, monitoring level and the OS output device. If a tree is rejected, choose Quiet Orbit or start a fresh recording. If WAV preparation fails, retry once on a finalized recording, then play the saved sample. Load the evidence locally ahead of time.

For a one-minute offline walkthrough, show the home image, paused Nebula Dreams session and export-ready screenshot in sequence.
