# Demo Script (Provisional)

Use the root application at http://127.0.0.1:8000/ after starting the local server.

1. Introduce Cosmic Echoes as a relaxing space-themed soundscape. Select an environment, choose Start session and place a root star.
2. Show the child echoes branching recursively. Change depth or the number of children and place another star to demonstrate the effect.
3. Try Quiet Orbit and enable Auto Meditation during playback. Enter and exit Focus Mode, then demonstrate keyboard placement and reduced motion.
4. Pause and resume to show synchronization, then stop and replay the saved composition.
5. Choose Prepare WAV, then Download WAV. Play a short excerpt in a local player. Let the session complete naturally if you want the export to include the effect tail. Clear the recording when finished.
